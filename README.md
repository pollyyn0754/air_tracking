# Учебный проект

## Описание:

**Air Tracking** — это бэкенд-сервис на Python для получения, обработки и хранения данных о самолетах в режиме, 
близком к реальному времени. Проект интегрируется с открытым API OpenSky Network и геокодером Nominatim (OpenStreetMap), 
позволяя получать информацию о воздушных судах, находящихся в воздушном пространстве конкретной страны.

## Установка:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/pollyyn0754/air_tracking
```

2. Установите зависимости:
```bash
pip install poetry
```
```bash
poetry install
```

3. Запустите основной скрипт:
```bash
poetry run python main.py
```

## Функциональность:

- **Поиск по стране:** Ввод названия страны (поддерживаются названия на русском и английском языках) для получения списка самолетов в ее воздушном пространстве.
- **Интеграция с API:**
  - **Nominatim (OpenStreetMap):** Преобразует название страны в географические координаты (bounding box).
  - **OpenSky Network:** Запрашивает данные о самолетах, находящихся внутри полученной области.
- **Обработка данных:**
  - Валидация входящих данных (идентификатор, страна, высота, скорость).
  - Преобразование сырого ответа API в структурированные объекты Python (`Aeroplane`).
- **Сохранение данных:** Возможность сохранения информации о самолетах в различные форматы файлов: CSV, Excel, JSON, TXT.
- **Анализ и фильтрация:** Полученные данные можно фильтровать по стране регистрации и сортировать по высоте полета.
- **Мультиязычность:** Поддержка ввода названий стран на русском языке с автоматическим переводом в международный 
  стандарт ISO.

## Основные компоненты:

Проект построен с использованием принципов объектно-ориентированного программирования и включает иерархию классов:

- **Абстрактный базовый класс `BaseAeroplane`** — определяет общий интерфейс для всех классов самолетов.
- **Класс `Aeroplane`** — наследуется от `BaseAeroplane` и реализует конкретную логику работы с данными о самолетах.
- **Абстрактный базовый класс `APIAdapter`** - используется для работы с API. Содержит общий метод _connect_to_api для отправки HTTP-запросов и обработки статус-кодов.
- **Класс `Aaeroplanes_api`** - наследуется от `APIAdapter` и реализует логику двухэтапного запроса к API:
  - Получение координат страны от Nominatim (OpenStreetMap).
  - Запрос данных о самолетах от OpenSky Network с использованием полученных координат.
- **Абстрактный базовый класс `FileSaver`**, определяет интерфейс для всех классов, работающих с файлами (добавление, удаление, получение данных):
  - **Класс `CSVSaver`** работает с CSV-файлами.
  - **Класс `ExcelSaver`** работает с Excel-файлами (использует pandas).
  - **Класс `JSONSaver`** работает с JSON-файлами (поддерживает обновление существующих записей).
  - **Класс `TXTSaver`** работает с текстовыми файлами в формате ТХТ.


### Вспомогательные утилиты:

- **`country_provider.py`:** Содержит класс CountryProvider, который отвечает за перевод русскоязычных названий стран в их официальные английские наименования согласно стандарту ISO. Использует библиотеку pycountry и ручное сопоставление для распространенных сокращений (например, "рф" -> "Russian Federation").

- **`greeting_manager.py`:** Утилитарный класс для генерации приветствия в зависимости от времени суток.

- **`utils.py`:** Набор вспомогательных функций для фильтрации (filter_aeroplanes, get_aeroplanes_by_altitude), сортировки (sort_aeroplanes), вывода информации и парсинга пользовательского ввода.


### Тестирование
В проекте реализовано комплексное тестирование для обеспечения надежности и корректности работы всех модулей. Тесты находятся в пакете `tests/`.

Запуск всех тестов:
```bash
pytest
```
Запуск тестов с отчетом о покрытии кода:
```bash
pytest --cov=src --cov-report=html
```
После выполнения команды будет сгенерирован детальный HTML-отчет в папке `htmlcov/`, который показывает, какие строки кода были выполнены в процессе тестирования. Общее покрытие функционального кода тестами составляет 93%.
